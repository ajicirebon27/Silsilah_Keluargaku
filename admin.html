    Laporan Hubungan Keluarga

    Cari nama untuk melihat keterangan hubungan keluarganya secara otomatis (anak ke berapa, kakak/adik dari siapa, pasangan, dan anak kandung).

    Keterangan Hubungan Keluarga

      Cek Hubungan Kekerabatan dengan Orang Lain

      Pilih 1 orang lagi untuk melihat sebutan kekerabatannya (mis. sepupu, paman/bibi, keponakan, mertua, ipar) dengan orang yang sedang dilihat di atas.

      Komentar Masuk

      Pohon Keluarga

      Klik lencana bulat − di bawah kotak nama untuk menyembunyikan keturunannya, atau lencana +N untuk menampilkannya lagi.

      Sampah

      Orang yang dihapus dari tab Data Orang muncul di sini dulu, bukan langsung hilang. Bisa dipulihkan kapan saja, atau dihapus permanen kalau memang sudah yakin.

      Log Aktivitas

      Catatan siapa menambah/mengubah/menghapus data, kapan, dan aksi apa yang dilakukan -- berguna untuk melacak perubahan data, terutama kalau suatu saat lebih dari 1 orang punya akses admin. Log ini hanya bisa dilihat lewat panel admin, tidak tampil ke publik.

      Jelajah Keluarga

      Klik nama untuk melihat pasangan & anaknya, satu keluarga per layar -- sama seperti fitur Jelajah pada tampilan publik. Tombol "Biodata" di sini langsung membuka form edit orang tersebut.

      Pengaturan Aplikasi

      ⚙️

      Umum

      Judul aplikasi & cakupan keluarga yang ditampilkan ke publik.

      ▾

      Pilih salah satu orang (misal leluhur paling awal) supaya tampilan publik -- pohon keluarga, pencarian, Laporan, dan Dashboard -- HANYA menampilkan orang ini beserta pasangan, orang tua/leluhurnya, dan seluruh keturunannya. Keluarga lain yang sama sekali tidak berkerabat akan disembunyikan total dari tampilan publik (data mereka tetap aman di database, tidak terhapus, dan tetap terlihat lengkap di sini pada tampilan admin). Kosongkan pilihan untuk menampilkan semua keluarga seperti biasa.

      Background Tampilan Publik

      ▾

      Backup & Restore Data

      Unduh cadangan data, atau pulihkan dari file backup.

      ▾

      Unduh seluruh data (orang, pernikahan, komentar, judul aplikasi, dan pengaturan Keluarga Utama) sebagai file cadangan.

      ⚠️ File ini berisi data pribadi lengkap keluarga (nama, tanggal lahir, alamat, nomor HP, foto). Jangan bagikan file ini ke grup WhatsApp/publik -- simpan hanya di penyimpanan pribadi kamu (mis. Google Drive milik sendiri, bukan folder bersama).

      Pulihkan data dari file backup JSON yang pernah diunduh. Data dengan ID yang sama akan ditimpa; data yang belum ada akan ditambahkan. Proses ini tidak bisa dibatalkan.

      🌳

      Ekspor / Impor GEDCOM

      Format standar silsilah keluarga, bisa dibuka di Ancestry, MyHeritage, FamilySearch, Gramps, dll.

      ▾

      Unduh seluruh data orang & pernikahan dalam format GEDCOM standar -- berguna untuk dibuka di aplikasi silsilah lain, atau sebagai arsip jangka panjang yang tidak terikat ke aplikasi ini.

      Masukkan data dari file GEDCOM yang diekspor aplikasi silsilah lain. Semua orang & pernikahan di file akan ditambahkan sebagai data baru (tidak menimpa data yang sudah ada) -- cek & rapikan lagi lewat tab Data Orang setelah impor, terutama kalau ada kemungkinan duplikat dengan data yang sudah ada.

      Catatan: hanya field dasar yang didukung (nama, jenis kelamin, tanggal/tempat lahir, tanggal wafat, agama, pekerjaan, alamat, catatan, relasi ayah/ibu/anak). Foto, sumber (citation), dan media dari file GEDCOM tidak ikut terbawa.
